# model/

The two training stages. They never talk to each other in code — only through files in `export/`.

| Stage | What it does |
|---|---|
| [`retriever/`](retriever/) | Two-tower (PyTorch). Embeds users + all ~22.8k anime into one 128-d cosine space → top-K candidates. |
| [`ranker/`](ranker/) | LightGBM lambdarank. Reranks the retriever's top 200 on 29 features. |

Two shared modules sit next to them: `paths.py` (the repo's local folders `data/`, `train/`, `export/`) and `recommender.py` (`Recommender`, the serving core: retrieve, rerank, cold section). `Recommender` is the only thing `service/` imports from `model/`.

## The export bundle

`export/` (repo root) is the firewall: **retriever writes, ranker + service read.** The ranker and service may import model *definitions* (e.g. `UserTower`) but never training code, and only the ranker's own two files (`ranker.txt`, `ranker_meta.json`) are written by anything other than the retriever. Full schema — shapes, dtypes, provenance lives in `export/CONTRACT.md`, generated by `retriever/export.py`.

This is what lets the service stay untouched across retrains: new model, same file names, same shapes.

## Retrain loop

Run in order; each step's output feeds the next.

```bash
# 1. retriever: data/clean → train/retriever/data → best.pt → export/
for s in model/retriever/data_prep/0[1-6]_*.py; do venv/bin/python "$s"; done
venv/bin/python model/retriever/data_prep/99_verify.py
#    train on a Colab GPU: python -m model.retriever.runs train final --preset final,
#    then download its best.pt into train/retriever/runs/
venv/bin/python -m model.retriever.export && venv/bin/python -m model.retriever.check_export

# 2. ranker: export → pools → model → export/
venv/bin/python -m model.ranker.data_prep.build_eval
venv/bin/python -m model.ranker.eval --baseline-only     # sanity gate — must pass before training
venv/bin/python -m model.ranker.data_prep.build_train
venv/bin/python -m model.ranker.train_lgbm
venv/bin/python -m model.ranker.eval                     # select winner
venv/bin/python -m model.ranker.export
```

Training location: retriever needs a GPU (Colab); the ranker trains locally on CPU (~40 min).
